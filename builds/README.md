# Artha Android Builds

Here are the ready-to-test APK builds for your Android phone.

### Downloads

1. **`artha-release-signed.apk` (Recommended - 26 MB)**
   - R8-optimized release build with stripped debug symbols, fast start time, and SQLCipher encryption.
   - Pre-signed with Android standard key so you can install it directly.

2. **`artha-debug.apk` (Debug Build - 35 MB)**
   - Full debug symbols and debug logging enabled.

---

### How to Install on Your Android Phone

1. Download `artha-release-signed.apk` directly to your phone (from this repo or GitHub Releases).
2. Tap the downloaded `.apk` file in your phone's notification or file manager.
3. If prompted by Android:
   - Allow **"Install unknown apps"** or **"Install from this source"** for your browser or file manager.
4. Tap **Install** and open **Artha**.
5. All data is 100% offline-first and encrypted via SQLCipher on your device!
